Política de Privacidade - TQT-App

O TQT-App é um aplicativo desenvolvido com o objetivo de disponibilizar informações educativas e auxiliar familiares e cuidadores no cuidado de crianças traqueostomizadas.

1. Coleta de dados

O TQT-App não coleta nem envia dados pessoais dos usuários para servidores externos. As informações inseridas no aplicativo, incluindo dados cadastrados sobre a criança, informações relacionadas à cânula, anotações, checklist e informações da agenda, são armazenadas localmente no dispositivo do usuário, por meio de um banco de dados SQLite.

2. Uso das informações

As informações inseridas pelo usuário são utilizadas exclusivamente para fornecer as funcionalidades do aplicativo, como organização de informações, anotações, agenda, checklist e demais recursos disponíveis.

3. Compartilhamento de dados

O TQT-App não compartilha os dados inseridos pelo usuário com terceiros e não realiza o envio dessas informações para servidores externos.

4. Armazenamento e segurança

Os dados são armazenados localmente no dispositivo em que o aplicativo está instalado. A proteção desses dados também depende dos mecanismos de segurança utilizados no próprio dispositivo, como senha, PIN ou biometria.

5. Exclusão dos dados

Como os dados são armazenados localmente, eles podem ser removidos por meio das funcionalidades disponibilizadas pelo aplicativo ou pela desinstalação do aplicativo, conforme o funcionamento da versão instalada.

6. Permissões

O aplicativo solicita apenas a permissão de notificações. Essa escolha é opcional.

7. Alterações nesta política

Esta Política de Privacidade poderá ser atualizada para refletir alterações nas funcionalidades do aplicativo ou nos requisitos legais e das lojas de aplicativos.
